Pertanyaan yang Sering Muncul

Jawaban spesifik untuk keberatan yang paling wajar sebelum membeli produk digital.

Apakah saya harus berlangganan tiap bulan?

Tidak. Aplikasi, game, eBook, dan jasa website di toko ini sekali bayar — file dan hasilnya milikmu. Satu-satunya pengecualian adalah Sewa Website + Hosting yang memang per bulan (harga sewa diumumkan segera), dan itu tertulis jelas di kartunya.

Bagaimana cara membeli produk di sini?

Website ini adalah hub katalog, bukan kasir — tidak ada keranjang atau checkout di sini. Tekan tombol beli di halaman detail produk: tombolnya menyebut platform tujuannya (misalnya “Beli di Payhip” atau “Beli di Zazzle”) dan pembayaran terjadi di platform itu — Gumroad, Payhip, Zazzle, Fiverr, KaryaKarsa, Swarms, PromptBase, Dreamstime, atau Adobe Stock. Produk yang belum ada di platform mana pun bertombol “Pesan via Email” ke masduki1189@gmail.com. Alur lengkapnya ada di seksi Cara Beli.

Benarkah ada demo gratis? Apa syaratnya?

Benar: 156 demo gratis bisa dibuka langsung di browser dan 3 aplikasi memang gratis penuh. Tanpa bayar, tanpa daftar, tanpa memasang apa pun. Setiap produk yang punya demo menampilkan tombol “Coba Demo” di halaman detailnya.

Setelah bayar, bagaimana saya menerima produknya?

File aplikasi, eBook, dan buku panduan dikirim ke emailmu setelah pembayaran terkonfirmasi. Game dimainkan lewat tautan di browser. Kaos POD dicetak dan dikirim fisik oleh Zazzle sesuai alamat yang kamu isi di sana.

Kalau aplikasinya error, bagaimana garansinya?

Ada garansi perbaikan bug sesuai tier: Basic 30 hari, Professional 60 hari, Bisnis 90 hari sejak penyerahan. Klaimnya cukup satu email ke masduki1189@gmail.com berisi nama produk dan kendalanya — tanpa formulir rumit.

Bisakah saya minta refund?

Kebijakan refund mengikuti syarat platform tempat kamu membayar (Payhip, Zazzle, dan sebagainya punya aturan masing-masing). Untuk pembelian via email, tanyakan ketentuannya sebelum membayar.

Bisakah aplikasi dibuatkan versi Android (APK)?

Bisa. Versi APK Android ditambah $25 dari harga tier aplikasi (misalnya Basic $29 menjadi $54 untuk APK). Untuk game, tambahan APK-nya Rp400.000. Sampaikan kebutuhan APK saat memesan lewat email.

Untuk jasa website, apakah domain dan hosting sudah termasuk?

Belum. Domain dan hosting tidak termasuk pada paket Pembuatan Website biasa. Paket “Pembuatan Website + Free Hosting” sudah termasuk hosting gratis (domain tetap terpisah), dan Sewa Website sudah termasuk hosting plus subdomain gratis.

eBook-nya ada paket bundel?

Ada. Bundel 3 eBook kisah nabi/tokoh Islam: $11.99 (harga satuan total $14.97 — hemat $2.98). Bundel 9 eBook: $24.99 (total satuan $44.91 — hemat $19.92). Pesan bundel lewat email masduki1189@gmail.com dengan menyebutkan judul-judulnya.

Kenapa sebagian produk berstatus “segera hadir” atau “harga via email”?

Karena toko ini menulis status apa adanya. Sembilan eBook kisah nabi dan tokoh Islam sudah punya cover dan halaman produk, tetapi penjualannya dibuka bertahap; enam game masih menunggu harga final. Untuk yang berstatus itu, tombolnya membuka email — tanya dulu, tidak ada kewajiban membeli.
